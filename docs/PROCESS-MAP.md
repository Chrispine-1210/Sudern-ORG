# SUDERN institutional operating spine

Community challenge / learner interest → Consent-controlled application → Authorised review → Cohort capacity check → Enrolment → Baseline assessment → Learning intervention → Final/follow-up assessment → Dated indicator observation → Evidence review → Executive governance decisions → Feedback / programme redesign.

Money controls run alongside programme interventions:

Funding agreement + receipt evidence → Restricted programme allocation → Expense request with supporting reference → Director approval AND finance-officer approval (distinct users; requester excluded) → Budget guard → Payment evidence registration → Audit trail → Outcome and budget reporting.

The platform implements the recordkeeping and workflow steps shown. It does NOT make payments, provide real accredited training, automatically select applicants, certify sources independently, or measure macroeconomic impacts.

### Suggested Malawi industry outcome strategy

- **Agriculture & agro-processing:** digital agribusiness records, value chain cost accounting, cooperative financial literacy, enterprise incubation; measure employment, input costs, production losses and verified enterprise sales.
- **Technology & services:** digital literacy, helpdesk and networking skills, practical projects; measure baseline/final competencies, job or paid contract follow-ups.
- **Manufacturing & repair:** maintenance, bookkeeping, quality and safety skills; track business productivity and verified customer orders.
- **Community finance:** financial education, records, savings and cashflow discipline; track sustained financial practice rather than raw attendance.

These are recommended programme directions, not claims of current SUDERN delivery. Publish targets only after budget, staffing, partners and baseline methods have been approved.
